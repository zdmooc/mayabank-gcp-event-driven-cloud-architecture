# ADR-010 — Synthetic Residual Value

Status: **Accepted for POC**.

The POC includes a deliberately simplified `SYNTHETIC_V1` residual-value calculation to demonstrate:

`vehicle data -> calculation -> event -> recommendation`.

It is not a market valuation model, credit/pricing model or financial advice. Inputs and coefficients are synthetic. Any real valuation capability would require authoritative data, calibration, model governance, legal/business ownership and monitoring.
