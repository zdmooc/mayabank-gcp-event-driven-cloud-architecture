# Ubiquitous Language

| Term | Meaning in this POC |
|---|---|
| Customer | Synthetic person/entity owning a financial relationship |
| External Customer Reference | Source-qualified identifier from a simulated upstream system |
| Golden Customer Identity | Internal canonical customer identity after matching; not a claim of MDM completeness |
| Customer Match | Explainable decision linking an incoming identity to a canonical customer |
| Contract | Synthetic finance, lease, loan, service or insurance relationship |
| Relationship | Read model combining customer, vehicles, contracts, recommendations and interactions |
| Golden Moment | Configured business condition that can justify a renewal/personalization action |
| Renewal Opportunity | Business opportunity derived from contract/vehicle conditions |
| Recommendation / Next Best Action | Deterministic, explainable action proposal in the MVP |
| Residual Value | Synthetic estimate used only to exercise data/event flows |
| Domain Event | Immutable statement that a relevant domain fact occurred |
| Integration Event | Published contract intended for consumption outside the owning context |
| Replay | Controlled reprocessing of previously failed/quarantined events |
| Idempotency | Property that duplicate processing does not create duplicate business effects |
| Evidence | Captured result proving a specific implementation/runtime claim |
