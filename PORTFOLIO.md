# Portfolio — GCP Event-Driven Automotive Financial Services

## One-line CV version

Conception d'une architecture de référence **Digital Financial Relationship Hub sur Google Cloud** pour un contexte synthétique de financement automobile : microservices Cloud Run, Pub/Sub/Eventarc, APIs, customer matching, agrégation de contrats, renouvellement/Golden Moments, moteur de recommandations, Terraform, IAM/WIF, BigQuery, observabilité, résilience, DLQ/replay et CI/CD.

## What this repository is intended to prove

The repository is designed to demonstrate an Architect's ability to move from a market/business need to:

- business capabilities and bounded contexts;
- HLD/LLD and architecture decisions;
- REST APIs and event contracts;
- event-driven integration patterns;
- GCP workload/data/security mapping;
- Terraform and CI/CD;
- reliability patterns and operational runbooks;
- observability and measurable NFRs;
- an evidence pack suitable for an Architecture Board or technical interview.

## Current maturity

At this stage the **research, domain architecture and HLD baseline are DESIGNED**. Application runtime, Terraform apply, GCP deployment, resilience tests, performance results and cost measurements are not yet claimed.

## Synthetic-domain statement

This is a fictional **Maya Automotive Financial Services** platform. It does not reproduce or claim to represent any real automotive manufacturer, captive finance company or banking information system. No real customer data or proprietary client implementation belongs in this repository.
